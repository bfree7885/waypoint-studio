# Historical Incident Library

**Schema:** `schema-incident-v0.1.json` (`inc_*`)  
**Index:** `intelligence/cyber/knowledge/incidents/index.json`

---

## Record fields

Timeline · Background · Affected technologies · Lessons learned · Mitigations · Long-term impact · Connections to related incidents · `subjectIds` into the shared graph

---

## Kinds

Ransomware campaigns · Supply chain · Cloud outages · Large-scale vulnerabilities · Infrastructure events

Incidents are literacy wrappers — campaign/CVE facts live in `cy_*` entities; the library adds lessons and cross-incident links.
