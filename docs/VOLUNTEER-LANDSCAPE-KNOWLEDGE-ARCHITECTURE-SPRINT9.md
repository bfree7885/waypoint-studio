# Knowledge Architecture Review — Volunteer & Landscape Interpretation (Sprint 9)

## Shared philosophy

Observation → understanding → stewardship. Volunteer discovers **what good to do**; Landscape Interpretation teaches **why the place looks this way**. Neither owns a competing observation notebook.

## Landscape Interpretation model

```
Observation tags (user)
    → Rule packs (transparent IF/THEN)
    → Interpretations (hedged stories + alternatives + field checks)
```

Taxonomy categories: land-use history, forest development, water, geology, habitat structure.

## Volunteer model

Opportunity Intelligence over a **demo catalog**: categories, seasonality flags, accessibility notes, family flags, distance from origin, weather suitability. Private planning statuses stay on-device.

## Citizen science bridges (no duplicated data models)

| Opportunity type | Continue in |
| --- | --- |
| Bird / habitat surveys | Fieldry |
| Cover / wildlife sign | Sheds |
| Season / site foraging context | ForageCast |
| Visual evidence | Scenes / Photo Coach |
| Place process reading | Landscape Interpretation |

Volunteer lists the meetup; other apps keep the observation record.

## Explicit non-goals

- Volunteer management / CRM
- Social followers / likes / rankings
- Speculative AI land-history generation
- Duplicate WOS schemas inside Volunteer
