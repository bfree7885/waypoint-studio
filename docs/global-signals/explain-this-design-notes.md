# Explain This — design notes

## Intent

Explain This is the signature Global Signals surface: a calm place to ask *why* and receive a structured path — not a chat bot, not a news feed.

## Composition

1. Brand + short mission (hub header)
2. Honesty banner (sample/demo)
3. Question field + Explain / Clear
4. Four curated example prompts (product demos)
5. Explanation sections in a single readable column

## Trust rules

- Facts vs analysis stay labeled via confidence / horizon on every hop.
- Waypoint’s Take appears only when a linked industry record already contains `waypointsTake`.
- Missing linked records → honest gaps list, not filler copy.
- No AI generation of edges, takes, or evidence.

## Visual

Reuse Global Signals landing tokens (deep navy field, mint accent, IBM Plex). Chain UI mirrors Relationship Explorer cascades so literacy transfers across modules.
