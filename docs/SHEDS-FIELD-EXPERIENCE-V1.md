# Sheds Field Experience V1

**Date:** 2026-07-15  
**Mission:** Transform Sheds from a usable map page into a premium outdoor navigation field app.  
**Out of scope (honored):** prediction science, ML/AI, species expansion, accounts, sync, social.

---

## Goal

When someone opens Sheds they should think: *“This feels like a real outdoor navigation app.”*

The map is the product. Everything else supports the map.

---

## Major design decisions

| Decision | Why |
|----------|-----|
| Absolute full-screen map | Removes stacked chrome that stole the field viewport |
| Floating FAB rail (Locate · Track · Layers · Notes · More) | Matches Gaia/onX-style glove-friendly controls |
| Floating bottom sheet for “Today’s Search” | Keeps suggestion glanceable without covering terrain when collapsed |
| Translucent HUD + nav pill | GPS status stays visible without a webpage header |
| Soft priority wash + lower default opacity (42%); heat layer deferred until first compute | Terrain remains readable; basemap wins first paint |
| OSM default basemap (Topo available in Layers) | Reliable tile fill vs sparse OpenTopoMap at overview zoom |
| Neutral gray unloaded-tile background | Gaps look like loading, not a broken dark hole |
| Forest/field palette (no purple chrome) | Reads as outdoor product, not generic dark web UI |
| Loading skeleton + offline banner | Trustworthy empty states instead of blank tile flashes |
| Accuracy circle + optional heading stub | “Where am I?” is never ambiguous when GPS is available |

---

## UX improvements shipped

### Priority 1 — Full-screen map
- Map shell is `position: absolute; inset: 0`
- Brand reduced to a floating chip; status moved behind **Info**
- Measured phone map share **≥ 85%** of viewport height (was ~69% in prior reliability pass)

### Priority 2 — Floating controls
- Right-side FAB rail with large touch targets and short labels
- **Layers** opens Map & model (opacity, overlays, weights)
- **Center** appears only when panned away from follow mode

### Priority 3 — Bottom sheet
- Collapsed peek: title · confidence stars · direction/distance
- Expanded: stats grid, explanation, coverage actions, session note
- Smooth max-height animation (respects reduced motion)

### Priority 4 — Navigation focus
- Pulsing GPS indicator
- Accuracy (±m) and heading when available
- Distance/bearing to suggested target in nav meta
- Accuracy circle + bearing stub on the map

### Priority 5 — Heat visualization
- Softer translucent cell colors
- CSS `mix-blend-mode: soft-light` on heat layer
- Opacity slider labeled in percent (default 42%)

### Priority 6–10 — Hierarchy, motion, mobile, empty states, polish
- Visual hierarchy: me → suggestion → terrain → controls → sheet
- Sheet slide, FAB press, GPS pulse, heat fade
- Safe-area aware; portrait first; landscape usable
- Loading cover + offline status
- Typography: Source Serif 4 + IBM Plex Sans; field radii and elevation

## Remaining improvements for V2

1. True compass / device orientation API with permission UX  
2. Drag-to-expand bottom sheet (grabber gesture), not tap-only  
3. In-map search / place jump  
4. Cached offline tile pack indicator (beyond online/offline banner)  
5. Polished history list UI (replace `<pre>` dump)  
6. Field-optimized model panel (presets first; weights behind “Advanced”)  
7. Optional bearing line that tracks live heading continuously  
8. Landscape control rail reflow for short phones  
9. Prefer OpenTopoMap automatically once zoomed into field scale  
10. Stronger first-paint tile prefetch for tall phone viewports  

---

## Known limitations (honest)

- Prediction science is unchanged (by design).  
- Headless/CDP overview zoom can still show progressive tile fill; field zoom after Locate is the intended experience.  
- OpenTopoMap remains optional (Layers) because it is sparse at continent overview.  
- Client-side rate limits and GitHub Pages hosting constraints still apply.  
- Device compass requires a future permissions pass.
