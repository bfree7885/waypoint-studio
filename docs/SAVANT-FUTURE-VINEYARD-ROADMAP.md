# Future Vineyard Engine — Roadmap

**Date:** 2026-07-18  
**Status:** Phase 1 educational scenario engine shipped; precision path planned.

## Phase 1 (shipped)

- Property metric bundle with why-it-matters copy
- Grape preference models (GDD windows, disease/frost sensitivity)
- Horizons: 0 / 5 / 10 / 15 / 20 / 25 years
- Simple warming heuristic (°C/decade → GDD shift)
- Full explanation paragraphs per grape per horizon
- Honesty: scenario-estimate, not climate downscaling

## Phase 2 — Evidence upgrade

1. Ingest elevation/slope/aspect from DEM tiles at click
2. Bind rainfall / humidity / frost dates from climate normals
3. Replace hardiness heuristic with zone polygons
4. Persist analysis snapshots per site for compare-over-time

## Phase 3 — Multi-model futures

1. Offer multiple warming pathways (low / mid / high) with labeled sources
2. Disease pressure surfaces from humidity × rainfall climatology
3. Irrigation demand estimates under water-stress scenarios
4. Confidence intervals instead of single educational fit %

## Phase 4 — Production decision support (still educational unless licensed)

1. Parcel boundaries + soils overlays
2. Cold-air drainage modeling from fine DEM
3. Grower notes / treatment journal (private)
4. Export PDF “site briefing” with sources cited

## Non-goals

- Guaranteeing yield or wine quality scores
- Replacing a viticulturist or extension agent
- Hiding uncertainty behind glossy precision
