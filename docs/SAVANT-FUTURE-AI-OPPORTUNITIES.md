# Savant — Future AI Opportunities

**Date:** 2026-07-18

## Fit for optional AI (always labeled)

1. **Note → structured traits** — LLM extracts acidity/oak/body from tasting prose into palate features (human-editable).
2. **Conversational why** — generate richer explanations from the same transparent feature vector (never invent cellar facts).
3. **Photo label OCR** — assist bottle entry; confirm before save.
4. **Multi-scenario climate narratives** — explain differences between low/mid/high pathways using cited datasets.
5. **Sommelier chat grounded on WIE package** — answers must cite palate/cellar/vineyard fields already computed.

## Guardrails

- No fabricated vintages, critic scores, or retailer stock.
- No medical claims.
- Prefer retrieval over generation for catalog facts.
- Keep deterministic engines as source of truth; AI as narrator/extractor.
