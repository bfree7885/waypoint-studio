## Product

- **Learning profile** — focus, improving, neglected, revisited, depth, breadth, interdisciplinary links, momentum, confidence.
- **Understanding Map** — Discovered → Mastering; auto from use; optional manual override.
- **Learning opportunities** — missing prerequisites, weak support, undefined references, disconnected project items, searched-but-thin notes.
- **Next steps** — ≤5 suggestions with explicit **why** (projects, prereqs, research, questions, goals, bridges).
- **Cross-disciplinary sparks** — curated bridges + multi-project hinges.
- **Learning timeline** — discoveries, finished reading, answered questions, research conclusions.
- **Project intelligence** — living hubs with missing knowledge, references, questions, disciplines.
- **Reading workspace** — highlights / margin notes / definitions / questions / future research on items; reference library lane.
- **Search as research assistant** — nearby, hubs, follow-ups, projects, questions around the top hit.
- Home reframed as a **learning companion** (not a notebook dashboard).
