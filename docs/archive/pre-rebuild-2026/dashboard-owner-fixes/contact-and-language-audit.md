## Issue 1 — Contact opened the wrong shell

### Root cause

Outside (Dashboard) footer Contact was built by `wds-app-shell.js` as studio-root `../../contact.html`. That page is a valid App Shell studio Contact surface, but it **leaves the quiet Outside product shell** (different product chrome / depth-0 studio-home framing). Owner expectation: Contact stays inside the rebuilt Waypoint Studio / Outside experience.

Noscript links on `apps/dashboard/index.html` also pointed at `../../contact.html`.

### Fix

1. Added `apps/dashboard/contact.html` — quiet chrome, `data-product="dashboard"`, shared contact form + `wds-contact.js`.
2. `WDS.appShell.contactPageHref()` routes Dashboard Contact (and bug/feature helpers) to in-product `contact.html` when already under `/apps/dashboard/`.
3. Noscript Contact → `./contact.html`; home link → `./` (Outside).
4. Brand / Waypoint Studio links still resolve to rebuilt studio home (`../../`).
5. Root `contact.html` retained for studio-directory footer (intentional current shell, not pre-App-Shell legacy).

## Issue 2 — Homework / assignment language

### Observed (before)

- Label: **Do this**
- Night primary: `Tonight: short outdoor check, then rest`
- Generator / Spec voice treated the slot as imperative agency

### Homework phrases found (Outdoor OS path)

| Phrase / pattern | Where | Replacement approach |
|------------------|-------|----------------------|
| Do this (label) | render + prefs meta | **Best window** |
| Tonight: short outdoor check, then rest | interpret night | Tomorrow morning looks more promising / Tonight remains quiet… |
| Tonight: quiet outdoor check under … | interpret night | Tonight remains quiet under … (alternate) |
| Take a walk… | interpret defaults | Conditions favor a walk… / Mildest hours… |
| Step outside briefly… | compose fallback | A brief look outside helps… |
| Finish outdoor time… | interpret rain-later | The stronger outdoor window looks… |
| Postpone / Stay clear / Avoid / Skip / Keep outdoor… | interpret safety | Observational risk framing |
| Alternate: | interpret alts | Also worth noticing: |
| If you still go: | constraints | Worth knowing: |
| tonight’s check (Happening support) | interpret H5 | tonight stays quiet, or tomorrow’s first window… |
| Tune what “Do this” prefers | prefs panel | Tune what “Best window” prefers |
