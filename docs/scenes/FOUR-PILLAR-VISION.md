## Four-pillar vision (direction, not ship state)

Preserve this shape in internal docs and planning. Do **not** present it as current product capability on public hubs or primary nav.

1. **Observe** — careful looking, field awareness, shoot review.
2. **Understand** — Photo Coach feedback, private growth signals.
3. **Create** — Living Scenes motion, Scene Builder environments (future / preview).
4. **Share** — optional Photographer Profile / quiet sharing (future / preview; never required).
