# SignalTerrain V0.9

**Status:** Hosting inspected. **Not deployed.** Not a public product launch. Not merged to `main`.

**Runtime (unchanged):** `/apps/summit-signal/` (do not occupy `/apps/signalterrain/`).

SignalTerrain V0.9 is a field-test deployment, not a public product launch.

V0.9 did **not** publish a HTTPS field-test URL. The existing Waypoint Studio host can only ship this app by merging to production `main` or by overwriting production Pages from this branch. Both are forbidden by the V0.9 gate.

If a GitHub Pages URL is later used, that URL would be **unlisted, not access-controlled.** GitHub Pages on this public repository has no authentication.

## Blocker (STOP)

Deployment requires merging SignalTerrain into production `main`, **or** an equivalent production Pages overwrite.

The V0.9 instructions require a stop when that is true. No deploy was performed. No `pages.yml` dispatch. No DNS change. No Sheds-host publish. No occupation of `/apps/signalterrain/`.

### What would go wrong if we “just shipped the branch”

`workflow_dispatch` of `pages.yml` on `cursor/summit-signal-v0-1-9f7b` would publish **this entire branch** to `https://waypointstudio.org`, replacing current production (Dashboard, DFD, Articles, Sheds cutover, etc.) with whatever differs from `main`. That is not an isolated field-test.

Merging to `main` then letting Pages run would put `/apps/summit-signal/` on the public Studio host. Even with `noindex` + robots Disallow + no nav link, that is still an **unlisted production path**, not a private phone lab, and it is a **main merge**.

On `https://waypointstudio.org` (or any HTTPS Pages URL):

- HTTPS: yes (Pages + custom domain).
- Geolocation: browsers allow a permission prompt on HTTPS. GPS is opt-in. The app works if denied/unavailable.

## Network dependency matrix (V0.8 behavior; unchanged)

| Surface | Kind | Default field-test behavior |
| --- | --- | --- |
| Application shell (HTML/CSS/JS) | Static same-origin | Required to load the app |
| Leaflet | Static same-origin | Required for the map |
| Summit catalogue | Static same-origin fixture | `data/ss-summits-w2-gc.json` unless `?live=1` |
| OSM access | Static same-origin fixture | Slide/Hunter fixtures unless `?access=live=1` |
| Pedestrian route | Static same-origin fixture | Slide/Hunter fixtures unless `?route=live=1` |
| Elevation profile | Static same-origin fixture | Matching elev fixtures unless `?route=live=1` |
| AZ terrain | Static same-origin fixture | Slide/Hunter DEM fixtures unless `?az=live=1` or `?route=live=1` |
| Basemap tiles | **Live external** (Esri) | Always fetched when the map is shown |
| IBM Plex fonts | **Live external** (Google Fonts) | Optional for layout |
| GPS | Browser API | Opt-in; not required |
| Copy Plan / coordinates | In-memory + clipboard | Local |
| Personal checklist | `localStorage` | Per summit, local |
| Session catalogue cache | `sessionStorage` | Local |

**SignalTerrain is not offline-capable.** Without network, Esri tiles fail. Without the static host, the shell and fixtures fail.
