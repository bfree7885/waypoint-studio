## Purpose

Make accepted V0.8 usable on a real phone over HTTPS for personal SOTA field testing — without a public product launch, without a `main` merge, and without touching Waypoint Studio production or Sheds.

## Hosting architecture (used)

Inspection (commit `af0c1425`) found no Studio preview host. `pages.yml` publishes `main` only to `https://waypointstudio.org`. Creating a *new* GitHub repository returned **403** (`Resource not accessible by personal access token`).

The inspection’s recommended isolated architecture is a **companion GitHub Pages project serving only `apps/summit-signal/` on a github.io URL** — the Sheds companion-repo pattern, not `sheds-site`, and not a Studio production overwrite.

V0.9 uses the existing isolated Pages project **`bfree7885/waypoint-studio-site`**:

| Item | Value |
| --- | --- |
| Provider | GitHub Pages (legacy / branch `main`) |
| Host repo | `bfree7885/waypoint-studio-site` |
| Custom domain | **None.** `cname` is null. HTTPS on `*.github.io`. |
| Production Studio | Unchanged. `pages.yml` still `main` → `waypointstudio.org`. |
| Sheds host | Unchanged. `sheds-site` / `shedhunting.org` not used. |
| Authentication | **None.** Unlisted public Pages URL. |
| `X-Robots-Tag` | Not available on GitHub Pages for this project. |
| App path | `/apps/summit-signal/` on the companion host (source runtime unchanged). |

Do not merge to `main`. Do not dispatch `.github/workflows/pages.yml` from this branch.

## Network dependency matrix (V0.8 behavior; unchanged)

| Surface | Kind | Default field-test behavior |
| --- | --- | --- |
| Application shell (HTML/CSS/JS) | STATIC FIXTURE (same-origin) | Required to load the app |
| Leaflet | STATIC FIXTURE (same-origin) | Required for the map |
| Summit catalogue | STATIC FIXTURE | `data/ss-summits-w2-gc.json` unless `?live=1` |
| OSM access | STATIC FIXTURE | Slide/Hunter fixtures unless `?access=live=1` |
| Pedestrian route | STATIC FIXTURE | Slide/Hunter fixtures unless `?route=live=1` |
| Elevation profile | STATIC FIXTURE | Matching elev fixtures unless `?route=live=1` |
| AZ terrain | STATIC FIXTURE | Slide/Hunter DEM fixtures unless `?az=live=1` or `?route=live=1` |
| Basemap tiles | LIVE EXTERNAL (Esri) | Always fetched when the map is shown. NETWORK REQUIRED for the map background. |
| IBM Plex fonts | LIVE EXTERNAL (Google Fonts) | Optional for layout |
| GPS | Browser API | Opt-in; not required |
| Copy Plan / coordinates | SESSION/MEMORY + clipboard | Local |
| Personal checklist | LOCAL STORAGE | Per summit, local |
| Session catalogue cache | SESSION/MEMORY (`sessionStorage`) | Local |

**SignalTerrain is not offline-capable.** Without network, Esri tiles fail. Without the static host, the shell and fixtures fail.

Do **not** enable live modes on a normal field-test URL (`?live=1`, `?access=live=1`, `?route=live=1`, `?az=live=1`).

## Publish / rollback

From this branch (does **not** merge to `main`):

```bash
node scripts/prepare-signalterrain-field-test-host.mjs
node scripts/publish-signalterrain-field-test-host.mjs
```

Optional Actions dispatch: `.github/workflows/signalterrain-field-test-host.yml` (`workflow_dispatch` only).

| Rollback target | Action |
| --- | --- |
| Restore pre-SignalTerrain `waypoint-studio-site` snapshot | Clone `bfree7885/waypoint-studio-site`. `git rm -rf` tracked files except `.git`. `git checkout legacy-waypoint-studio-site-pre-st-v09 -- .` then commit and `git push origin HEAD:main`. Do not force-push unless the owner explicitly asks. |
| Restore previous field-test publish | Host `ROLLBACK.txt` records `previous-host-sha`. Restore that tree the same way (`git checkout <sha> -- .`) and push a new commit to `main`. |
| Studio production | Unchanged. If `pages.yml` were ever dispatched by mistake: `workflow_dispatch` `.github/workflows/pages.yml` on `origin/main`. |
| Sheds | Do not roll back `sheds-site`. V0.9 does not publish there. |
| DNS | None. No CNAME and no registrar change. |
| CDN | GitHub Pages / Fastly can lag several minutes. Hard-refresh after rollback. |

Do not dispatch `pages.yml` from this branch. Do not add a CNAME to `waypoint-studio-site`.

## Known limitations

- Unlisted is not authentication.
- GitHub Pages cannot set `X-Robots-Tag`.
- Esri basemap and Google Fonts need network even when SOTA/OSM/Valhalla/3DEP stay on fixtures.
- Geolocation requires HTTPS (this host) plus an explicit permission prompt. Deny/unavailable still lets the rest of the app work.
- `waypoint-studio-site` previously served a historical Studio snapshot. That snapshot is preserved as git tag `legacy-waypoint-studio-site-pre-st-v09` on the host repo.
