## Hosting architecture (chosen)

Inspection (commit `af0c1425`) found no Studio preview host. `pages.yml` publishes `main` only to `https://waypointstudio.org`. Creating a *new* GitHub repository returned **403**.

The inspection’s recommended isolated architecture is a **companion GitHub Pages project serving only `apps/summit-signal/` on a github.io URL** — the Sheds companion-repo pattern, not `sheds-site`, and not a Studio production overwrite.

This increment implements that architecture against the existing isolated Pages project **`bfree7885/waypoint-studio-site`** (no CNAME, HTTPS github.io, not production Studio, not Sheds):

| Item | Value |
| --- | --- |
| Provider | GitHub Pages (legacy / branch `main`) on `waypoint-studio-site` |
| Intended app URL | `https://bfree7885.github.io/waypoint-studio-site/apps/summit-signal/` |
| Custom domain | **None.** Must not add a CNAME. |
| Production Studio | Unchanged. `pages.yml` still `main` → `waypointstudio.org`. |
| Sheds host | Must not be used. `sheds-site` can receive this PAT; V0.9 refuses it. |

Prepare/publish scripts and a dispatch-only workflow are in this repo. Do not merge to `main`. Do not dispatch `.github/workflows/pages.yml` from this branch.
