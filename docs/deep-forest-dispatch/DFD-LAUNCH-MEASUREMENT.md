# DFD launch measurement

**Goal:** Learn what earns discovery and deeper Waypoint exploration.  
**Rule:** No invented success thresholds. Search can take weeks.

## Sources we can use

| Source | What it gives |
| --- | --- |
| Google Search Console (after owner setup) | Indexed pages, impressions, clicks, queries, CTR, landing pages |
| YouTube Studio (after videos publish) | Impressions, CTR, views, AVD, % viewed, traffic sources |
| Waypoint DFD hooks | `DFD_LIBRARY_VIEW`, `DFD_STORY_VIEW`, `DFD_RELATED_STORY_CLICK`, `DFD_WAYPOINT_TOOL_CLICK`, `DFD_VIDEO_PLAY`, `DFD_YOUTUBE_CLICK` via `waypoint:analytics` / `__WAYPOINT_ANALYTICS_QUEUE__` |

Do **not** install a second analytics platform for this experiment.

## Checkpoints

| When | Focus |
| --- | --- |
| **Initial baseline** | Confirm live URLs, sitemap coverage, hooks fire in browser console if debugging |
| **~2 weeks** | Any GSC impressions? Any YouTube impressions if Video #1 is up? |
| **~30 days** | Queries / landing stories / CTR patterns emerging? |
| **~60 days** | Cluster winners (water / sand / geology / satellite / weather)? Video→story visits? |
| **~90 days** | Decide next content mix — still **no** auto-backlog from gaps alone |

## Questions every checkpoint

1. What is getting impressions?  
2. What gets clicks?  
3. Which stories get search traffic?  
4. Which queries are emerging?  
5. Which YouTube titles/thumbnails get clicks?  
6. Where does video retention drop?  
7. Do video viewers visit Waypoint?  
8. Do article readers open another story or a tool?  
9. Which subject clusters are winning?

## Anti-vanity

- Page count ≠ success  
- Rankings without engagement are weak  
- Do not chase volume topics that fail the Waypoint original-value test  
- Do not declare SEO win from anecdotes
