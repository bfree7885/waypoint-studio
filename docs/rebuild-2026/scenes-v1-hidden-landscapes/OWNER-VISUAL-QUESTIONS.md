# Owner visual questions — Hidden Landscapes + Animal Vision

For each real photograph in `real-photo-matrix/`:

1. Did Hidden Landscapes reveal something meaningful?
2. Did I learn something I couldn't immediately see?
3. Does Animal Vision teach rather than entertain?
4. Does the visualization preserve the identity of the photograph?
5. Is scientific uncertainty represented honestly?
6. Does this feel like Waypoint?

Also check:

- Luminance / tonal / concentration feel observational, not filter-like
- Color families are environmental observation, not a palette generator
- Structure edges/texture read as discovery
- Estimated depth is clearly INFERRED
- Deer / canine simulations are labeled SIMULATED
- Bee / bird UV show UNAVAILABLE, not invented patterns
- Mobile 390 screenshots are photo-first
- Exports (when used) keep epistemic labels
