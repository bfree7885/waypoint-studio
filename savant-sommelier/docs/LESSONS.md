# Lessons

## 2026-10-12 — Local foundation

The first screen can be useful before any scientific source is attached, as long as every empty panel says what is missing. A real basemap is not a license to draw parcel lines or scores on top of it. The camera frame for New York and Pennsylvania is a rectangle for the opening view, and the copy has to say that it is not a state line.

The web app and the API share `shared/honesty.json` so a sentence and a map frame cannot drift between the two. Readers in the browser drop any payload that pretends an integration is already connected.
