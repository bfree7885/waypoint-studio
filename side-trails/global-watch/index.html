Global Watch

Open-source intelligence situational awareness.

Detect change. Identify unusual activity. Correlate independent evidence. Assess what the evidence supports.

Standalone application — not embedded in Studio. Owner field-test MVP: not production-hardened, not commercially available, not operationally authoritative.

Launch

Start the field-test host in the Global Watch repo, then open the app: 

cd /path/to/global-watch
npm ci
npm run build
npm start
# → http://127.0.0.1:4173
