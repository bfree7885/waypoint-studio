Waypoint Deck

Offline-first Linux field computer built around local AI, navigation, communications, knowledge, and situational awareness.

In development — early-stage direction, not a finished product.

What it is

Waypoint Deck explores what a useful personal field computer looks like when local capability comes first — and the network is optional.

Modern tools often assume constant connectivity. Deck asks the opposite: what remains useful when the link is poor, delayed, or gone?

Not a Studio app

Waypoint Studio is the consumer ecosystem — Dashboard, Scenes, and Sheds — with shared Publishing. Studio is about discovering, understanding, and exploring the world.

Waypoint Deck is an independent Side Trail: a resilient offline field computer. It shares Waypoint’s interest in geography and field information, but it is not another Studio subscription application.

Core direction

Intended capability areas — planned / being explored, not claimed as shipping features:

  • Navigate — offline maps, GPS, waypoints, terrain and field navigation.
  • Understand — local AI and offline encyclopedias / reference libraries.
  • Observe — weather, environmental information, and eventually attached sensors.
  • Listen / communicate — radio/SDR and related communications tools.
  • Know what’s happening — when connectivity exists, useful external signals; when it disappears, cached information and local capability.
  • Ask the Deck — a local AI / chatbot intended as the primary interface tying systems together.

Questions the Deck is meant to help with

Eventually, a user should be able to ask things like:

  • Where am I?
  • What’s the weather doing?
  • What am I receiving?
  • What information do I have available?
  • What’s changed?
  • What’s happening?

The intended synthesis draws from whatever the Deck has: weather, GPS, maps, radio/SDR, sensors, offline knowledge, system/power status, cached information, and — when online — external situational-awareness signals.

Those inputs are capabilities of the Deck, not separate Waypoint products. Online signal integration is not built yet.

Honest status

This page describes direction and intent. It does not ship Deck OS, local AI, SDR, sensors, or online signal integration from this website. No fake hardware renders or capability demos are shown here.

Commercial intent (internal): one-time Deck OS purchase with optional one-time packs — not a recurring Studio subscription. Pricing is not published here.
