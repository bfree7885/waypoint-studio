Waypoint Deck

Waypoint Deck

A local-first Linux field computer for when the network is optional: maps, navigation, local knowledge, communications, weather, and sensors.

In development — direction is public; this page does not claim a finished product.

What it is

Waypoint Deck explores what a useful personal field computer looks like when local capability comes first — and the network is optional.

Modern tools often assume constant connectivity. Deck asks the opposite: what remains useful when the link is poor, delayed, or gone?

Not a Studio app

Waypoint Studio is the web ecosystem — Dashboard is the Studio product, with Shed Hunting as a sibling field destination and Waypoint Publishing. Studio is about observing, discovering, and understanding the world outdoors.

Waypoint Deck is a distinct field-computing project: a resilient offline computer. It shares Waypoint’s interest in geography and field information, but it is not another Studio subscription application.

Capability areas

Intended directions. Status is labeled honestly — nothing here is claimed as finished unless marked existing.

  • Navigate — offline maps, GPS, waypoints, and field navigation. In development / planned.
  • Understand — local AI and offline reference libraries. Planned.
  • Observe — weather, environmental information, and attached sensors. In development / planned.
  • Listen / communicate — radio/SDR and related communications tools. Planned.
  • Field data — notes, observations, and incident/resilience tools on the device. Planned.
  • System awareness — power, connectivity, and what the Deck currently has available. Planned.

Questions the Deck is meant to help with

Eventually, a user should be able to ask things like:

  • Where am I?
  • What’s the weather doing?
  • What am I receiving?
  • What information do I have available?
  • What’s changed?
  • What’s happening?

The intended synthesis draws from whatever the Deck has: weather, GPS, maps, radio, sensors, offline knowledge, system/power status, and cached information when a link exists.

Honest status

This page describes direction and intent. It does not ship Deck OS, local AI, SDR, or sensors from this website. No fake hardware renders or capability demos are shown here.

Commercial intent (internal): one-time Deck OS purchase with optional one-time packs — not a recurring Studio subscription. Pricing is not published here.
