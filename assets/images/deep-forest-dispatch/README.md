## Provenance rules

- Prefer NASA / USGS / NOAA public-domain assets when possible.
- Keep credit strings on pages (hero captions + Sources & credits).
- Educational derivatives must be labeled as such — never presented as raw sensor products.
- Do not strip attribution when adding assets.
