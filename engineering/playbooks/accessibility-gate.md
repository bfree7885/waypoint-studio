# Accessibility gate

Release Manager / QA must confirm:

- [ ] Skip link present on primary shells
- [ ] Focus visible on Apps button and launcher controls
- [ ] Launcher closable with Escape
- [ ] Local nav `aria-current` on active feature
- [ ] No keyboard traps in launcher
- [ ] Text contrast remains readable on active states
- [ ] Mobile does not rely on two stacked horizontal app nav rows

Mark pass/fail in the sprint `verification.gates.accessibility`.
