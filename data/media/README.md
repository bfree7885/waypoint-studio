# Shared website media catalog

Approved assets only. Updated by `python -m photo_pipeline decide … --publish`.

- `catalog.json` — index consumed by `design-system/js/media/waypoint-media-api.js`
- `approved/<id>/` — web derivatives (thumbnail/small/medium/large/hero/background)

Originals remain in `~/Pictures/Waypoint Library/` and are never stored here.
