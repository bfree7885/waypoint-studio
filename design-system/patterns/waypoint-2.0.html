Design System 2.0

Contemporary Field Station

Topographic Atlas · High-Desert / Southwestern Landscape. Natural, warm, restrained, scientific, editorial — southwestern field technology at dusk. One earth family. Terracotta is the signature. Purple is supporting.

Canonical palette

Muted sand/bone, terracotta, ochre, desert purple, sage, charcoal/espresso. Not neon. Not tourist-Southwest. Purple is supporting, not the ground.

Contour · restraint · latitude

Semantic tokens

Prefer --wp-*. Compatibility: --wds-* and --ws-* map onto the same values.

TokenPurpose
--wp-bg / --wp-surface / --wp-elevatedPage, panels, raised chrome (charcoal → espresso)
--wp-text / --wp-text-secondary / --wp-text-mutedCopy hierarchy (WCAG AA on charcoal)
--wp-brandLocked terracotta — Waypoint square, never the product accent
--wp-accent / --wp-accent-gold / --wp-accent-purple / --wp-accent-fieldProduct pairing + supporting hues
--wp-focus / --wp-focus-ringKeyboard focus (ochre, never color-only status)
--wp-success / --wp-warning / --wp-danger / --wp-infoStatus — always pair with label or icon
--wp-space-* / --wp-radius-* / --wp-shadow-*Spacing, radius, elevation
--wp-header-h / --wp-max-content / --wp-transition-calmLayout + motion

For future agents

  • Import design-system/css/wds.css (pulls tokens). Canonical docs: docs/DESIGN-SYSTEM-2.0.md.

  • SignalTerrain / Global Signals may keep product chrome, but surfaces should resolve through tokens.
  • Never invent parallel design stacks. Extend product accents via [data-product].
